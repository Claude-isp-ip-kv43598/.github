<p>这篇文章按问答的顺序推进，因为选型这事本来就是一串具体问题：要不要买、买几条、怎么验、什么时候该走。我不喜欢给「推荐清单」，那东西三个月就过期；更愿意把判断的路径讲清楚，你自己走到哪一步就知道该做什么。先把最常见的第一个问题摆出来。</p>

<h2>一、号一多就出事，问题真在 IP 上吗？</h2>
<p>不一定，但 IP 是最先该排除的一项。账号数量上来之后，出问题的概率天然上升，因为任何一个环节的不一致都会被放大。这时候不要急着换服务商，先做一次分组对照：把出事的号和新开的号按出口地址分组，看是否某一组特别集中。</p>
<h3>先看是不是集中在同一段地址</h3>
<p>把近三十天的出口地址导出来，按前三段分组统计出事比例。某一组的事故率明显高于其他组，说明问题在地址段；各组的比例差不多，说明问题更可能在设备、配置或使用节奏上。</p>
<h3>再看是不是集中在同一台机器</h3>
<p>同样的分组方法，这次按机器分。一台机器上挂的配置文件越多，缓存和本地存储互相串的概率越大。如果事故集中在某一台，先把它上面的号分散开，再观察一轮。</p>
<p>最后才看账号本身。排除了地址和机器，剩下的才轮到账号。账号侧的差异主要在注册信息的完整度、使用节奏的规律性，这两项是自己能调的部分，而且往往比换线路更有效。</p>

<h2>二、「不共用出口」到底怎么算不共用？</h2>
<p>这句话在合同里没有标准定义，不同的卖家说的可能是三件事：这个地址只给你一个人用、这个地址同一时刻只有你连、或者这个地址所在的段不再分给别人。三种含义的保证强度差很远。</p>
<h3>单地址独享是最常见的一档</h3>
<p>指的是这一个地址不与其他客户共用，但同段的邻居地址可能分给了别人。对多数小团队来说这一档就够，前提是同段密度别太高，最好不超过五条。</p>
<h3>整段独享才谈得上段级隔离</h3>
<p>整段独享指的是一个 C 段只供你使用，段内的地址关系由你自己安排。门槛高、价格也高，账号规模到三十个以上再考虑，账号少的时候单号成本会被摊得很高。</p>
<h3>「同一时刻只有你连」是另一回事</h3>
<p>这一档说的是并发隔离：地址可能被别人拿到过，但同一时刻只有你在用。它解决不了历史关联的问题，只解决当下争抢的问题。问清楚属于哪一档，再谈价格。</p>

<h2>三、起步阶段该买几条？</h2>
<p>起步不要一次买齐。最省钱也最稳妥的做法是买两条：一条用于主用账号，一条留作对照和热备。两条的意义在于你能做 A/B 比较，出了问题有替换对象，而不是所有账号一起停摆。</p>

<h3>一个账号一条是基准线</h3>
<p>这条线不用商量。两个账号挤一条地址，等于人为制造关联，后面省下的钱要用稳定性来还。真觉得贵，就减少账号数量，而不是把账号堆到一条线上。</p>
<h3>按账号数加一条余量</h3>
<p>十个账号配十一条，多出来的那条做热备。热备线不挂账号，平时空着或者只做连通性探测，一旦某条线出问题可以直接切过去，不用等新地址分配。</p>
<p>起步先买短期。第一次合作按月付甚至按周付，跑满一个完整周期再谈更长周期。这一条能帮你避开大部分踩坑成本，因为多数问题在第一周就会暴露。</p>

<h2>四、怎么验证供应商说的独享是真的？</h2>
<p>没法百分之百验证，但能把可疑的排除掉。做四步：查归属、查类型、查密度、查并发行为。前三步用公开工具，第四步靠自己的观察。</p>
<h3>归属与类型：十分钟能查完</h3>
<p>whois 看 ASN 是否挂在住宅宽带运营商名下；两三个 IP 情报站交叉看标签是否一致标为住宅。若标签里出现托管或代理，说明这条线不是住宅段，与「住宅 IP」的说法不符。</p>
<p>密度：只能问，但要问得具体。「同 /24 已经卖出去多少条」比「是不是独享」有效得多。答不出具体数字、或者说「没统计过」的，就按密度偏高来假设，自己在分配时留出余量。</p>
<h3>并发行为：挂一天看日志</h3>
<p>用自己的账号连续挂 24 小时，记录是否有非自己触发的连接重置。同一条地址若被别人同时使用，重置会以你无法解释的方式出现，时间点也和你自己的操作对不上。</p>

<h2>五、什么时候该从这条路换走？</h2>
<p>换供应商是有成本的：重新配环境、重新适应、重新观察。所以要有明确的换出条件，而不是一出问题就换。我自己的三条线是这样的。</p>
<h3>条件一：同一个问题重复三次</h3>
<p>同一个现象在按流程排查后仍然复现三次，且服务商给不出具体原因，就该考虑换。注意是同一个现象，不是三次不同的现象。</p>
<h3>条件二：替换流程走不动</h3>
<p>提出替换后超过承诺时间没有响应，或者替换来的地址仍然是同一段、同一个 ASN，说明对方的资源池就那么大，换也换不出新东西。</p>
<h3>条件三：价格与用量彻底错配</h3>
<p>用量降到每月不足三十小时，却还在付整月的独享费用，这不是供应商的问题，是方案选错了。这时候换的是计费方式，不一定是供应商。</p>

<h2>常见问答</h2>
<h3>刚开始只有两三个号，值得上独享吗？</h3>
<p>答：值得，但要买短期。号少的时候单号成本看着高，可一旦出事，排查时间也是成本。两三个号配两条地址，一条主用一条热备，是最省心的起步配置。</p>
<h3>双 ISP 的两条线要分给不同账号吗？</h3>
<p>答：要。两条线的 ASN 不同，天然适合做分组：一组账号固定走一条，另一组走另一条。混着用会让每个账号的出口在两家之间跳，稳定性反而不如单线。</p>
<h3>怎么判断某条线是不是住宅段？</h3>
<p>答：whois 看 ASN 与注册机构名，再用两三个 IP 情报站看类型标签。三项结果一致指向住宅宽带运营商，才算通过；标签冲突时按更严格的那个算。</p>
<h3>热备线平时空着会不会浪费？</h3>
<p>答：会浪费一点，但比全线停摆便宜。可以让热备线承担低优先级的任务，比如日志上报或连通性探测，既保持活跃又不占用主账号资源。</p>
